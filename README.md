## Overview

Wing Slot adds a dedicated equipment slot specifically for wing items in Terraria, allowing players to equip wings for flight without occupying one of the standard accessory slots. This effectively grants an extra accessory slot for wing users, significantly increasing endgame build flexibility.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Wing Slot** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Dedicated Wing Slot** | Wings equip in a separate slot and do not use an accessory slot |
| **Full Compatibility** | Works with all vanilla and modded wing items without exceptions |
| **Visual Equip** | Wings display correctly on the character model from the dedicated slot |
| **Vanity Option** | Vanity wings can be applied in the slot for cosmetic-only appearance |
